# 恋爱知识库简化为文档

按用户2026-11-07纠正，本方案取代上一版必须先建宝典的交互：

- 参照营销键盘的文档页：居中标题、右上角添加菜单、搜索框、白色文档列表。
- 根页直接展示文档；添加菜单只有新建文档和导入本机文档，没有文件夹或宝典创建。
- 点击直接进入完整正文编辑页，支持标题、正文、启用状态、保存；列表更多菜单提供编辑、启停、确认删除。离开未保存编辑时确认。
- 应用资产内置完整狗头军师知识库（固定上游版本及MIT声明），首次使用复制到本地文档，只安装一次，不覆盖后续编辑，不恢复用户删除的内容。
- 旧版本文件夹中的文档按原ID、标题、正文、启用状态和更新时间迁移为平铺文档，不丢失旧资料。
- 键盘选择一个具体文档，严格只检索该文档；新编辑会话仍默认不选，保留资料快照与旧请求失效机制。
- 验证新增默认文档首次安装、重复读取、用户修改/删除、旧资料迁移、单文档范围与实际文档列表；保留模型请求及正常/密码框触摸回归。
