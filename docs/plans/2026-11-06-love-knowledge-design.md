# 恋爱知识库实施

按用户提供的《恋爱键盘-恋爱知识库功能参考》实施，文档中上一轮“只交付方案”不是本次任务限制。

- 原生 App 底部增加知识库，保持其他菜单；独立私有 JSON 原子存储，宝典和文档增删改、启用停用。
- 首版导入 TXT/MD，UTF-8/GB18030，1MB/30万字限制，先预览编辑再保存。
- 帮你回文字回复、超会说表达优化主动单选宝典；默认不选，新编辑会话重置选择，关系设置独立保留。
- 本地关键词检索，重叠分段，最多4段、4800字预算，仅选中库的启用文档，无匹配不提供片段。
- 每次请求保存不可变片段快照；同一份快照用于模型输入和参考面板。资料作为不可信参考数据。
- 请求代次、编辑会话、模式、原文、关系、模型设置、提示词和资料版本共同校验，回填前再次检查。
- 单测覆盖严格单库、停用、无匹配、长文末尾、预算和快照；构建与隔离安装真机测试覆盖持久化和管理页，原键盘正常/密码编辑框回归。

手机通过 ADB `svc power stayon true` 保持接电常亮。原 `stay_on_while_plugged_in` 为2，恢复命令 `adb shell settings put global stay_on_while_plugged_in 2`。
